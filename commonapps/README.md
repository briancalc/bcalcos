## 1. Introduction

BcalcOS provides Devuan-compatible packages of several upstream software applications that are not currently available in the Devuan repository.

These packages are not forks of the upstream projects. BcalcOS packages the official upstream releases for convenient installation through the BcalcOS APT repository.

Packages are maintained on a best-effort basis and may not always track the latest upstream release. Updates are provided after they have been packaged and tested for compatibility with BcalcOS.

⚠️ **Warning:**
 While BcalcOS does not include built-in telemetry, packages you choose to install may.  Please consult the applications' manuals.

## 2. Marp 

Creator: https://marp.app/

Upstream project: https://github.com/marp-team/marp-cli

Functionality: converts Markdown files into presentations and other output formats, including HTML, PDF, PowerPoint, and images.

Telemetry: none to our knowledge.

---

## 3. QOwnNotes

Creator: https://www.qownnotes.org/

Upstream project: https://github.com/pbek/QOwnNotes

Functionality: plain-text note-taking application with Markdown support and with optional integration with Nextcloud Notes.

Telemetry: includes automatic metrics functionality so users concerned about telemetry should disable in settings.

---

## 4. Flacon

Creator: https://flacon.github.io/

Upstream project: https://github.com/flacon/flacon

Functionality: audio file encoder and decoder that extracts individual tracks from a single album image file, such as FLAC, WAV, or APE. 

Telemetry: none to our knowledge.
