01 / BUNDLE

Packages

Data that's needed to run.

A package bundles an application with its version, dependencies, and installation scripts. It includes metadata telling the system what the software requires and how to configure it. This helps ensure consistent, reliable installations that are easy to update and maintain.

02 / CONTROL

Package Manager

Tracks the packages.

The package manager installs, updates, and removes software while resolving dependencies automatically. On Devuan, dpkg handles low-level .deb operations, while apt provides a user-friendly interface for searching repositories, managing upgrades, and keeping your system synchronized.

03 / STOREHOUSE

Respositories

Holds the code.

Repositories are online collections of packages, organized by version and architecture. In Devuan, these stores align with the project’s init-free philosophy, ensuring all software integrates cleanly with the system.

Flathub complements the native apt system by offering sandboxed Flatpak applications. While apt manages core system components, Flathub provides self-contained desktop apps that run independently of the base system—ideal for frequently updated tools without risking system stability.

04 / SCRIPTS

Applications

Programs to run.

Applications are the programs you interact with daily—browsers, editors, media players, and utilities. In BcalcOS, these are delivered as packages from verified repositories, allowing for clean installation, seamless updates, and safe removal via the package manager.

05 / AVAILABLE

BcalcOS Apps

Your software.

BcalcOS users have access to the robust Devuan repository, a selection of custom applications in the BcalcOS respository, and the Flatpak applications available via Flathub. Together, this gives you instant access to thousands of reliable, compatible applications.
